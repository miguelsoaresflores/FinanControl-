# 💰 FinanControl

Sistema de controle financeiro pessoal em Python com interface gráfica e banco de dados local. Permite cadastro de receitas, despesas e metas, com relatórios e gráficos.

---

## ✨ Funcionalidades

- Cadastro de receitas
- Cadastro de despesas
- Definição de metas financeiras
- Relatórios com gráficos
- Banco de dados SQLite
- Interface gráfica intuitiva

---

## 🛠️ Tecnologias

- Python 3.x
- SQLite
- Tkinter
- Matplotlib

---

## 📁 Estrutura do projeto

O projeto está organizado na pasta `src/` com os seguintes módulos:

- `main.py` - Ponto de entrada da aplicação
- `interface.py` - Interface gráfica
- `database/database.py` - Configuração do banco de dados
- `models/` - Modelos de Receita, Despesa e Meta
- `relatorios/graficos.py` - Geração de gráficos
